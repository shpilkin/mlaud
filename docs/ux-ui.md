> 0.1–0.5). С 2026-09 интерфейс проектируется заново вокруг главного окна —
> [ux-app.md](ux-app.md). Здесь в силе остаются §2 (иконка и её состояния), §5

> ux-app.md §4–5 и §7.


## 1. Форм-фактор

**Нативное приложение в строке меню macOS** (menu bar / status bar app), запускается из **.dmg**
двойным кликом, не из терминала. Иконка постоянно висит в правом верхнем углу (как на скриншоте
пользователя). Приложение само выполняет роль «сторожа» (заменяет launchd) и оркестрирует
обработку, но **не держит ML-модель в своём процессе** (см. §6, NFR-2).

## 2. Иконка в строке меню и её состояния

Монохромная template-иконка (адаптируется к светлой/тёмной теме). Состояния:

| Состояние | Иконка | Смысл |
|---|---|---|
| Ожидание | контур волны/микрофона | слежу за папкой, дел нет |
| Обработка | анимированная (пульс/спиннер) + опц. бейдж с числом | идёт транскрипция, в очереди N |
| Готово (кратко) | галочка на ~2 сек | последний файл обработан |
| Ошибка | иконка с красной точкой | была ошибка, нужен взгляд |
| Пауза | приглушённая / значок паузы | слежение приостановлено |

## 3. Меню (по клику на иконку)

```
┌───────────────────────────────────────┐

│ ● Ожидание — слежу за папкой           │  динамический статус
```

## 4. Окно настроек

Отдельное окно, разделы:

- **Папки**
  - iCloud Inbox (откуда забирать): `…/iCloud Drive/ASR/ASRInbox/AllRecords` — кнопка «Выбрать…».
  - Папка вывода (локально): `~/ASR/ASROutput/AllOutputs`.
  - Архив аудио (локально): `~/ASR/Processed/AllRecords`.
  - Кнопка «Создать структуру папок» (автосоздание дерева).
- **Telegram**
  - Bot Token, Chat ID.
  - Кнопка «Проверить» → шлёт тестовое сообщение, подтверждает связь.
- **Транскрипция**
  - Вариант модели: `rnnt` / `ctc` / `e2e_rnnt` (по умолчанию `rnnt`).
  - Язык: авто / ru / ru+en.
- **Диаризация (Фаза 2)** — раздел задизейблен до реализации
  - Переключатель «Размечать спикеров».
  - HuggingFace Token (для pyannote).
- **Поведение**
  - ☑ Удалять аудио из iCloud после приёма.
  - ☑ Хранить аудио локально (архив).
  - ☑ Отправлять транскрипт в Telegram (файлом).
  - ☑ Показывать системные уведомления.
- **Автозапуск при входе** ☑.

## 5. Уведомления и обратная связь

- **Системные уведомления macOS** (в дополнение к Telegram):
  - успех: «Готово: 21.06 14:30 — планёрка (3 мин)» → клик открывает `.txt`;
  - ошибка: «Ошибка обработки 09:10 — <причина>» → клик показывает детали.
- В меню всегда виден текущий статус и список последних результатов.
- Прогресс при длинном файле: статус «Транскрибирую… (N из M)».

## 6. Архитектура процессов (важно для памяти)

```
[Menu bar app] (всегда жив, лёгкий: rumps + PyObjC, ~десятки МБ, БЕЗ модели)
   ├─ FSEvents watch на ASRInbox/AllRecords
   ├─ подписка на NSWorkspaceDidWake (пробуждение → sweep)
   ├─ таймер-страховка (sweep раз в 1-2 мин)
   └─ при появлении файла → spawn:
        [worker subprocess] (эфемерный)
           ├─ грузит GigaAM-v3 (MLX) ← RAM занялась
           ├─ обрабатывает весь пакет
           ├─ пишет вывод, шлёт в Telegram, архивирует аудио
           └─ exit ← RAM освободилась
   └─ читает статус/прогресс воркера (через файл состояния/пайп) → обновляет иконку и меню
```

Так выполняется NFR-2: модель в памяти **только во время прогона**; постоянный процесс —
лёгкий менюбар-сторож.

## 7. Первый запуск (onboarding)

1. Приветствие, краткое объяснение.
2. Папки: подтвердить/выбрать → автосоздание структуры (iCloud inbox + локальное дерево).
3. Telegram: вставить Bot Token и Chat ID → «Проверить» (тестовое сообщение).
4. Разрешения macOS: Уведомления; при необходимости Доступ к диску (для папки iCloud).
5. Предложить «Запускать при входе».
6. Готово — иконка появляется в строке меню.

## 8. Упаковка и поставка (.dmg) — РЕШЕНО

**Стек (выбран):** **нативное Swift-приложение** (AppKit/SwiftUI) для строки меню, окна настроек,
уведомлений и login item (`SMAppService`). ML-конвейер — **Python-worker**, запускается Swift'ом как
**подпроцесс**; общение через границу процессов (файл статуса / stdout / код возврата) — не FFI.
Поставка — **неподписанный `.dmg`** (личное использование).

- **Веса моделей** не зашивать в бандл — качать при первом запуске в Application Support (меньше .dmg).
- **Gatekeeper:** при первом запуске неподписанного приложения — разовый «Открыть» через правый клик /
  Системные настройки. Бесплатно.
- **Python-окружение worker'а** упаковать внутрь бандла (venv в Resources) либо ссылаться на
  uv-окружение — финальный способ см. OQ-10.

Почему Swift, а не Python+py2app: py2app с MLX/torch хрупок и даёт тяжёлые бандлы; мост Swift↔Python
не нужен, т.к. worker — отдельный подпроцесс; нативный UX лучше. См. ADR-012.
