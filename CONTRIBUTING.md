# Как предложить изменение

Репозиторий открыт для чтения. Писать в него напрямую может только владелец.

1. Сделай fork репозитория.
2. Внеси изменения в отдельную ветку своего форка.
3. Открой pull request в ветку `main` этого репозитория.
4. Владелец посмотрит изменения. В `main` попадает только то, что он одобрил и влил сам.

Баги и идеи — через Issues.

Не прикладывай к issue и pull request токены, `chat_id` и аудиозаписи с чужими голосами.
